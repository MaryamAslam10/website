About This Webpage

This interactive web page is designed as a STEM Educational Quiz that helps learners test their knowledge in a fun and engaging way. It was created using HTML, CSS, and JavaScript — three core web technologies that work together to bring structure, design, and interactivity to a webpage.

🔹 Structure (HTML)

The entire webpage is built using HTML5 for structure. It includes a navigation bar with links to the Home, About, and Contact sections; a quiz container for displaying questions and options; and instruction and score sections to guide users and show results.

🔹 Styling (CSS)

The page uses CSS3 for styling, ensuring a modern, clean, and responsive layout. Important features include:

  • Soft background colors for better readability.
  • Rounded buttons with hover effects for better user interaction.
  • Smooth slide-down animations for the About and Contact sections using CSS transitions.
  • Responsive design that adapts to different screen sizes.

🔹 Interactivity (JavaScript)

The core functionality is written in JavaScript (ES6). It dynamically loads quiz questions, checks answers, keeps track of scores, and displays the final results. JavaScript is also used to control the visibility of different sections:

  • Clicking About hides the Home/Quiz sections and shows the About content.
  • Clicking Contact hides other sections and shows the contact form.
  • Clicking Home brings users back to the main quiz interface.
  • At the end of the quiz, the final score is displayed dynamically.

🔹 Formatting & Design Principles

The design follows key web design principles such as alignment, contrast, balance, and readability. Font sizes and colors were carefully chosen for accessibility and ease of understanding. Buttons and containers use box shadows and border-radius for a modern look.

🔹 Learning Value

The project demonstrates how basic web technologies can be combined to create an educational tool. It reinforces concepts of DOM manipulation, event handling, conditional logic, and dynamic rendering using JavaScript. Overall, it’s a great example of how technology can support interactive learning in STEM education.

Instructions for Quiz

  • This quiz contains 10 multiple-choice questions related to STEM and Educational Technology.
  • Select the correct answer by clicking on the radio button.
  • You can use the 💡 Hint button (maximum 2 hints) if needed.
  • Track your progress with the progress bar at the bottom.
  • The quiz ends automatically if you answer all questions or make 3 wrong answers.
  • Use ⬅️ Previous and ➡️ Next buttons to navigate.
  • Try to answer each question carefully before moving on.
